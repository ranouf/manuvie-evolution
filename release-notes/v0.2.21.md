# 0.2.21

First complete Manuvie Evolution release, ready for validation and publication.

## Features

- Adds a Manuvie Evolution button directly inside the Manulife Wealth portal.
- Shows gains, returns, fees, and contributions for all accounts and individual accounts.
- Adds interactive charts with detailed tooltips.
- Adds a year-to-date contributions table with account and detail filters.
- Caches already loaded historical data to reduce unnecessary portal API calls.

## Chrome publication

- Adds the Chrome MV3 manifest, extension icons, and package build script.
- Adds demo screenshots with fake data.
- Adds the privacy policy.
- Prepares automated deployment to the Chrome Web Store.

## Quality and validation

- Adds Jest unit tests with coverage.
- Adds Playwright visual tests.
- Adds Prettier, ESLint, and TypeScript validation.
- Adds the local `ci-build.ps1` script to reproduce PR validation locally.
- Adds GitHub Actions workflows for PR validation, release notes, and deployment.
