# 0.2.21

Première version complète de Manuvie Évolution prête pour validation et publication.

## Fonctionnalités

- Affiche un bouton Manuvie Évolution directement dans le portail Gestion de patrimoine Manuvie.
- Présente les gains, rendements, frais et cotisations par ensemble de comptes et par compte.
- Ajoute des graphiques interactifs avec infobulle détaillée.
- Ajoute un tableau des cotisations depuis le 1er janvier avec filtres par compte et détail.
- Met en cache les données historiques déjà chargées afin de limiter les appels inutiles au portail.

## Publication Chrome

- Ajoute le manifeste Chrome MV3, les icônes et le script de build du package.
- Ajoute les captures d’écran de démonstration avec données fictives.
- Ajoute la politique de confidentialité.
- Prépare le déploiement automatique vers le Chrome Web Store.

## Qualité et validation

- Ajoute les tests unitaires Jest avec couverture.
- Ajoute les tests visuels Playwright.
- Ajoute la validation Prettier, ESLint et TypeScript.
- Ajoute le script local `ci-build.ps1` pour reproduire la validation du PR.
- Ajoute les workflows GitHub Actions pour la validation PR, la release note et le déploiement.
