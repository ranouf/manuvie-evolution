# Confidentialité

Manuvie Évolution fonctionne uniquement dans le portail `manulifewealth.myinvestorportal.ca`.

- Les données financières sont lues depuis les réponses déjà autorisées par votre session Manuvie.
- Aucun identifiant, mot de passe, code 2FA, relevé ou chiffre financier n’est envoyé à un service externe.
- Les données analysées sont conservées localement dans le stockage Chrome du profil courant afin d’éviter de recharger les années déjà lues.
- Le cache est indexé par investisseur et sert uniquement à accélérer l’affichage local dans le portail.
- L’extension ne contient aucun service d’analytique.
